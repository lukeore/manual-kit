Releasing a new issue

  1. Complete this issue's row: date, pages, what changed and why.
  2. Set issue and date in manual.json.
  3. Rebuild. The build must report overflow: none.
  4. Commit the sources, then push a manual-issue-N tag. CI publishes the PDF as a release.
