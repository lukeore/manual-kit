Conventions

Net colours. Every pinout, diagram and table uses the same colour for the same kind of net:

VBUS 5 V supply +3V3 3.3 V supply GND ground DATA data output SDA SCL I²C AUX general purpose ID identification EN control

Requirement tags such as PWR-03 point back to the clause in the source specification.

Signals ending in _n are active low.

Boxes

Warning: could damage hardware or break an interface rule. Read these before acting.
Information: background, tips and how-to. Nothing breaks if you skip it.
Reference: points to the page, specification, file or tool where the full detail lives.
